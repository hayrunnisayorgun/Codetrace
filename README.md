**# 🚀 Codetrace - AI Codebase \& Architecture Auditor**



**An autonomous, privacy-first developer tool that ingests GitHub repositories live, extracts architecture diagrams (Mermaid.js), and provides educational code insights using Microsoft Foundry Local.**



**## 🌟 Key Features**

**- ⚡ \*\*Live Ingestion:\*\* Paste any public GitHub repo URL.**

**- 🎓 \*\*Junior-Friendly Mentorship Mode:\*\* Explains \*why\* code is written a certain way and highlights design patterns.**

**- 🛡️ \*\*Confidence Score:\*\* Transparent evaluation of answer sources.**

**- 🎨 \*\*Visual Architecture:\*\* Dynamic module dependency graphs.**



**## 🛠️ Built With**

**- \*\*LLM Engine:\*\* Microsoft Foundry Local**

**- \*\*Backend:\*\* Python FastAPI \& SQLite**

**- \*\*Frontend:\*\* React + Tailwind CSS**
